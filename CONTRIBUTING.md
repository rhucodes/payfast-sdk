# Contributing

Thanks for your interest in contributing to the PayFast SDK.

**We are not accepting external contributions right now.** We're looking into opening the project up for contributions in the future, but for the moment the API and internals are still settling, so pull requests from outside the team will be closed.

In the meantime you can still help:

- **Report bugs** — open an issue with your SDK version, Node.js version, and a minimal reproduction.
- **Request features** — open an issue describing your use case; it helps us shape what to build once contributions open up.
- **Report security issues privately** — please do **not** open a public issue for anything security-sensitive. Email design@dominicmarule.co.za instead.

Watch this file, it will be updated with full contribution guidelines when we're ready to accept pull requests.
